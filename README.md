# Cafe

This application is timeboxed to be completed within 3 days.

The goal is to use the following dependencies:
Vite React
Tanstack
Material UI
ExpressJS/NodeJS

Caveat:

As much as possible, I tried to build it to the assignments requirements. However, I've not used Tanstack before and I briefly skimmed through the documentations to get a rough idea of what is needed for it to work. There might be best practices on how to write it.


## To run the application.

1. You will need to create a `.env` in the `./backend` with the following credentials in place.

```
PORT=3000
```

2. Once you've set your `.env` then you can run `docker compose up --build`. This should build both the API and UI containers.

3. Open your browser and start testing the UI  `https://localhost`
